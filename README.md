# Redis in Rust (Learning Project)

This project is my attempt to **learn Rust by building Redis from scratch**.  
The aim isn’t just to recreate Redis, but to gain a deeper understanding of systems programming, networking, and memory management while practicing idiomatic Rust.

## Resources

I’m following two excellent resources as the backbone of this journey:

- [CodeCrafters: Build Your Own Redis](https://app.codecrafters.io/courses/redis/overview) – a hands-on, guided project that breaks Redis down into achievable milestones.  
- [Build Your Own Redis](https://build-your-own.org/redis/) – a fantastic open-source resource that explores Redis internals and implementation details step by step.  

Both have been **unbelievably helpful resources**, and I highly recommend them to anyone interested in learning Redis internals or building a Redis-like system in a new language.

## Goals

By the end of this project, I aim to have:

- A working Redis clone implemented in **Rust**  
- A stronger grasp of **event loops**, **TCP networking**, and **memory management**  
- Practical experience with **idiomatic Rust patterns** that transfer into backend and systems programming work
